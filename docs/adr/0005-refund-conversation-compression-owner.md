# 退款会话压缩由外层编排统一管理

2026-11-19，用户确认按实际 token 预算自动压缩较早对话，由外层 LangGraph 统一管理消费者会话摘要，保留近期完整交互及独立结构化业务状态，原始聊天仍完整保存在 MySQL。选择统一的外层摘要管理，避免消费者历史在多个执行器内形成不同的全局摘要；代价是维护摘要版本、原始消息覆盖范围及调用前预算检查，DeepAgent 的局部上下文管理仅限当前子任务。工具调用与观察须成对处理，摘要不能重建退款授权或金额，摘要失败且无法保留必要上下文时暂停本轮并保留数据、不继续退款；具体预算和恢复边界见[上下文压缩设计](../../.scratch/refund-agent-all-tech-demo/context-compression.md)，尚未实施。
