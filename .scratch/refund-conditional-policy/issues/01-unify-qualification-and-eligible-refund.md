# 01 统一资格判断，打通合格办理

Status: ready-for-agent

Blocked by: 无

## 要实现的行为

普通查单和合格的退款资格咨询直接按可信订单事实答复。消费者已明确授权且订单符合条件时，通过现有退款服务办理模拟退款。资格咨询、办理前核验和退款事务内的最终核验共用一套确定性业务规则。参见[改造规格](../spec.md#业务规则与授权)。

## 验收标准

- [x] 普通状态查询和合格的退款资格咨询均为零次政策检索、零次退款提交。答复来自可信订单事实。
- [x] 合格且已授权的普通办理为零次政策检索、一次有效退款提交，依据业务回执答复模拟退款结果、金额和退款编号。
- [x] 同一组订单事实在资格咨询、办理前和事务最终核验中得到一致的业务资格结果。资格判断本身为零次模型调用，普通 `INTENT` 仍一次调用。
- [x] 提交事务使用锁定后的最新状态，保留本人订单校验、本轮单笔授权、提交记录、幂等和结果核对。已退款返回原结果，待核对时按既有路径核对。
- [x] 无有效授权或无法取得可信本人订单事实时零次提交。通过现有工作流入口验证回复和调用次数，并用隔离业务验证入口核对退款记录。
