# 03 处理主动询问政策和办理授权

Status: ready-for-agent

Blocked by: [02 按拒绝原因检索并解释](02-explain-qualification-denial.md)

## 要实现的行为

区分办理请求附带询问依据、先看条款再决定，以及把查到正式条款设为办理条件。消费者也可以单独咨询通用政策或本人订单的政策依据。参见[改造规格](../spec.md#业务规则与授权)和 [ADR-0012](../../../docs/adr/0012-refund-policy-for-explanation.md#办理授权和政策说明)。

## 验收标准

- [x] 通用政策咨询和明确的订单政策查询能返回经核实的适用依据。只读咨询和资格咨询补号的退款提交次数为零。
- [x] “帮我退这笔指定订单，顺便告诉我依据”在业务核验通过后办理一次。已确认的业务结果和真实回执始终可答复，依据不可核实时说明情况。
- [x] “看完条款再决定”与“如果查得到适用的正式条款就帮我退”都先处理政策问题，本轮退款提交次数为零。查不到所需正式条款时说明依据暂时无法核实。
- [x] 后续办理须由消费者在同一条新消息中明确要求退款并写出唯一目标订单号。只说“帮我退”或“退刚才那单”时追问，零次提交。随后明确授权且资格通过时可以办理。
- [x] 普通 `INTENT` 服务调用一次。目标歧义、否定、引用和历史指代的授权反例保持零误授权，办理指令和政策需求在现有工作流入口验证。
