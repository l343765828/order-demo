# 02 按拒绝原因检索并解释

Status: ready-for-agent

Blocked by: [01 统一资格判断，打通合格办理](01-unify-qualification-and-eligible-refund.md)

## 要实现的行为

普通退款资格咨询和办理先查订单。程序确认资格拒绝后按业务原因追加政策调查，消费者收到业务原因和可以核实的适用条款。参见[改造规格](../spec.md#退款调查与动态重规划)和 [ADR-0012](../../../docs/adr/0012-refund-policy-for-explanation.md)。

## 验收标准

- [x] 普通退款资格咨询和办理的初始 `PLAN` 只有查单步骤。提交前的明确资格拒绝最多追加一个政策步骤，正确更新步骤索引并执行。可恢复的流程状态和补查复用该步骤。
- [x] 从程序确认的拒绝原因构造首查与补查查询，只传必要的业务信息。补查沿用本轮政策版本快照和现有预算。
- [x] 回复仅使用出处、原文、版本、适用条件及相关例外都经过核验的条款。检索失败、结果为空、条款不适用或解释失败时，仍能回复已确认的业务原因。冲突会被记录，办理结果保持由程序决定。
- [x] 提交前确认已发货时，退款服务调用零次，新增退款记录零条。事务内才确认已发货时，退款服务调用一次，新增退款记录零条，退出事务后按该次拒绝原因回复。
- [x] 查单不可用、通信故障和退款结果待核对走各自的现有业务处理路径。只读政策解释对提交次数和业务结果没有影响。
