# 15 移除 Host 的政策文件依赖

**Status:** ready-for-agent

**Blocked by:** [05 政策发布与检索](05-publish-and-search-refund-policy.md)、[06 政策与资格咨询](06-answer-policy-and-order-eligibility.md)。

## 目标

Host 在没有本地政策 Markdown 的环境中，仅凭本轮真实 MCP 回执回答普通政策咨询和订单资格咨询。普通咨询从重排候选中选出适用的 FAQ 或正式条款，订单资格使用可信订单事实及正式条款。

## 范围

复用演示政策 `DEMO-REFUND-POLICY` 的 `1.0` 及现有 Milvus 集合，配套升级 Host 和 MCP。交付政策版本快照、基于回执的选答与引用核验，以及需要时的一次正式条款语义补查。首次读政策时由 MCP 返回固定演示版本对应的目录修订号，实际发布目录由 16 接入。

## 涉及的契约

- 删除 Host 的 `published_clauses()`、本地 Markdown 运行时读取、进程缓存和按条目完整内容比较。MCP 的 `search_policy` 按本轮版本过滤。普通咨询在同一检索中召回 FAQ 与正式条款，统一重排并返回最多三条。首个成功回执即使没有候选也携带目录修订号。
- FAQ 录入问题和答案。Host 把首轮返回的全部候选提供给选答模型，取消仅允许首位 FAQ 参与的限制。模型在候选中选最能直接回答问题且适用条件一致的一条，或判定全部不适用。排名和条目类型用于理解候选，各条均有参与选答的机会。
- 选中已发布 FAQ 时直接展示其答案正文，选中正式条款时展示适用条款原文。两种答复都引用所选条目的文档标题、版本和条目编号。演示 FAQ 正文末尾原有的出处文字按历史源内容处理，答复的出处以本轮选中的条目为准。引用核验按事件 ID、文档 ID、版本、条目编号及类型匹配本轮成功回执。普通咨询可引用 FAQ，订单资格和退款办理采用正式条款作为政策依据。
- 首轮成功但无适用候选时，Host 以消费者问题及必要的已核验订单事实，在同一目录修订内用 `search_policy` 做一次仅限正式条款的语义补查。补查仍无足够依据时提示依据不足，检索失败时提示暂时无法核实政策。
- 订单资格继续由代码根据可信订单事实确定，适用条款属于演示退款政策在本轮采用的版本。 [主设计](../spec.md#5-rag-文档与检索流程) · [MCP 契约](../mcp-integration.md#6-输入输出契约与事件关联)

## 验收标准

- [x] 在不提供政策 Markdown 的 Host 运行环境下，经真实 MCP 回答普通政策问题及本人订单资格咨询。普通答复的标题、版本、编号和内容来自所选 FAQ 或正式条款的回执，订单资格引用正式条款。
- [x] 在隔离验收数据中录入一条只有问答的 FAQ，让首轮同时返回正式条款与该 FAQ。FAQ 排在第二或第三且最适用时直接展示其答案及出处，首轮即完成答复；另验证粗略相关的 FAQ 排在第一而正式条款更适用时，选用正式条款。
- [x] 首轮三个候选均无法回答时，在相同目录修订内只进行一次正式条款语义补查。取得适用条款时用正式条款回答，仍查不到时提示依据不足。检索失败时提示暂时无法核实政策，普通查单仍可用。
- [x] 验证事件、文档、版本、条目编号、类型及原文均与成功回执一致。将 FAQ 当成订单资格的正式依据、混入其他版本或使用伪造原文时，核验失败。
- [x] 首次成功的空检索结果携带目录修订号。补查沿用本轮修订号，独立历史版本不会混入答复。
