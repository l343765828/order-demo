# 12: 长会话按 token 预算压缩并保留业务状态

**Status:** ready-for-agent

**Blocked by:** [08 多轮授权](08-manage-multiturn-refund-authorization.md)、[11 显式长期偏好](11-manage-explicit-preferences.md)。

## 目标

较长的咨询或办理对话仍可在已部署模型的窗口内继续。历史完整留库，无法安全保留必要上下文时明确暂停本轮。

## 范围

由外层 LangGraph 统一装配和预算检查，自动压缩较早完整交互并保存版本化摘要。验证当前结构化状态、近期原文、工具往返和当前偏好在压缩、失败与重启场景的行为。

## 涉及的契约

- `ConversationSummary`、`conversation_summaries` 中的 `revision`、覆盖消息序号、生成事件 ID。摘要通过来源及预算核验后追加版本，原文独立保存。订单、授权、取消、待办、计划与结果由结构化状态及业务记录管理。
- 按实际序列化输入 token、模板、工具／Schema、证据、输出预留及余量计预算。以目标部署窗口为准，记录基线为 8192。DeepAgent 的局部上下文只服务当前步骤。 [压缩设计](../context-compression.md) · [ADR-0004](../../../docs/adr/0004-refund-agent-storage-boundaries.md) · [ADR-0005](../../../docs/adr/0005-refund-conversation-compression-owner.md)

## 验收标准

- [ ] 长对话自动跨过压缩阈值，实测典型意图、规划和 DeepAgent 调用符合窗口及输出预留。摘要和近期消息来源不重不漏，工具动作和观察成对，未完成往返保留；重启后恢复有效摘要版本、覆盖范围和近期交互。
- [ ] 模拟旧摘要、原文和 checkpoint 均含已撤销授权、已换订单或已删除／更正偏好。压缩前后及重启后都只使用当前有效业务状态和偏好，无旧授权复活，无旧偏好覆盖当前值。
- [ ] 摘要失败且已验证上下文仍在预算内时可以继续；必要上下文超窗时明确暂停，保留原文和上一有效摘要，不产生新退款提交或写调用。失败摘要不覆盖已确认业务状态。
- [ ] 可读过程事件能核对压缩触发、预算、前后 token、摘要版本、覆盖范围及失败原因。工具输出和摘要不能授予新权限或充当最终政策证据。

## 验证方式

使用接近窗口的真实 Qwen 会话与可控 token 回归夹具，串联补单、取消、换单、偏好删除和未完成工具往返。对摘要生成／持久化和预算不足注入故障，检查 DB 原文与版本、重启恢复结果及 MCP 写请求数。
